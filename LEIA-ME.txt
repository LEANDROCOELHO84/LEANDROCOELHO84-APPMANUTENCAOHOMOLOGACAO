COMO SUBIR NO GIT / STREAMLIT CLOUD (homologação)
----------------------------------------------------------------
1. Extraia esta pasta (ou use o conteúdo como raiz do repositório).
2. NÃO commit secrets.toml real nem banco_chamados.db de produção.
3. Faça push para o repositório conectado ao Streamlit Cloud.
4. No Streamlit Cloud → Settings → Secrets:
   - Cole o conteúdo de .streamlit/secrets.toml.example
   - Preencha SQLITECLOUD_URL (topo), WhatsApp e Drive.
5. Redeploy / aguarde o app acordar.

----------------------------------------------------------------
INSTALAÇÃO LOCAL
----------------------------------------------------------------
1. Extraia esta pasta.
2. Copie seu banco_chamados.db (se já existir) para a raiz.
3. pip install -r requirements.txt
4. cp .streamlit/secrets.toml.example .streamlit/secrets.toml
   (preencha os valores)
5. streamlit run app.py

MÓDULOS DE AUTOMAÇÃO
----------------------------------------------------------------
  whatsapp_api.py / integracoes.py   → aviso WhatsApp na conclusão
  google_midia.py + apps_script_*.gs → fotos no Google Drive

  exportar_excel.py                  → exportações .xlsx
  relatorios_gestao.py               → MTTR, FTFR, backlog, produtividade,
                                       resumo alertas, SLA, preventiva vs corretiva
  relatorios_indices.py              → views e índices de gestão
  notificacoes.py                    → alertas no app
  schema_gestao_melhorado.sql        → índices + views SQL (idempotente)
